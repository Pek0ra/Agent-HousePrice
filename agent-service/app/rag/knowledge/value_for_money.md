“性价比”是歧义指标，不允许默认生成 SQL。可选口径包括：

1. 购房面积效率：`area / total_price`，需说明结果单位为平方米/万元，数值越高表示同样总价获得的面积更多。
2. 单位面积租金：`monthly_rent / area`，单位元/平方米/月；必须由用户确认数值越高还是越低代表“更优”。
3. 价格、交通、学区组合评分：当前视图没有交通和学区字段，不支持计算，不得伪造评分。
